🎯 FLUJO IMPLEMENTADO
═══════════════════════════════════════════════════════════════════════════════

1. USUARIO CONTACTA (Principal_Page)
   └─> Contact.tsx llena formulario
       └─> POST /api/public/contact (sin JWT)
           └─> Backend recibe datos

2. BACKEND PROCESA
   └─> contact_routes.py valida y procesaContactSchema.load()
       └─> ContactService.create_inquiry()
           └─> ContactInquiry se guarda en BD
               └─> Retorna inquiry_code (INQ-XXXXXXXX)

3. BD ALMACENA
   └─> contact_inquiry: 1 fila con consulta
       └─> message: 0 mensajes (vacío inicialmente)
           └─> Relación 1→N establecida

4. ADMIN VE EN DASHBOARD
   └─> Dashboard/MessagesModule.tsx (puerto 5174)
       └─> GET /api/admin/inquiries (con JWT)
           └─> Backend retorna lista de consultas
               └─> Admin ve tabla con filtros/búsqueda

5. ADMIN RESPONDE
   └─> Click en consulta (GET /api/admin/inquiries/<id>)
       └─> Ve detalles + historial
           └─> Escribe en textarea
               └─> POST /api/admin/messages
                   └─> Message se guarda
                       └─> Contacto.status → "contacted"
                           └─> Conversación actualiza
