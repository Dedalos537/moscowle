## 🔄 FLUJO DE PROCESAMIENTO

```
┌─────────────────────────────────────────────────────────────┐
│  ENTRADA: Base de datos (session_metrics)                   │
│  ├─ accuracy_rate (0-100%)                                  │
│  └─ average_time (segundos)                                 │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 1: Cargar datos                                       │
│  └─ Query: SELECT accuracy_rate, average_time FROM ...      │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 2: Normalizar                                         │
│  └─ StandardScaler: X' = (X - μ) / σ                        │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 3: Aplicar K-Means                                    │
│  ├─ Inicializar 3 centroides aleatorios                     │
│  ├─ Asignar cada punto al centroide más cercano            │
│  ├─ Recalcular centroides como promedio                    │
│  └─ Iterar hasta convergencia                              │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 4: Actualizar BD                                      │
│  └─ UPDATE session_metrics SET cluster_id = X WHERE ...     │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  PASO 5: Calcular métricas                                  │
│  ├─ Inertia (suma de distancias²)                          │
│  ├─ Silhouette Score (calidad -1 a 1)                      │
│  ├─ Estadísticas por cluster                               │
│  └─ Centroides en escala original                          │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│  SALIDA: JSON con resultado completo                        │
│  ├─ success: bool                                           │
│  ├─ centroids: Dict                                         │
│  ├─ clusters_summary: Dict con estadísticas                │
│  ├─ silhouette_score: float                                 │
│  └─ timestamp: str                                          │
└─────────────────────────────────────────────────────────────┘
```

## ⚙️ CÓMO USAR

```python
# 1. IMPORT
from app.services.ai_service import run_k_means_segmentation
from app.extensions import db
from app.models import SessionMetrics

# 2. EJECUTAR
result = run_k_means_segmentation(db, SessionMetrics, k=3)

# 3. VERIFICAR
if result['success']:
    print(f"✓ {result['updated_sessions']} sesiones actualizadas")
    print(f"✓ Silhouette: {result['silhouette_score']:.3f}")
else:
    print(f"✗ Error: {result['error']}")

# 4. USAR RESULTADO
for cluster_id, summary in result['clusters_summary'].items():
    print(f"{cluster_id}: {summary['size']} estudiantes")
```

## 📊 MÉTRICAS DE CALIDAD

```
Silhouette Score
├─ 1.0  → Clustering perfecto
├─ 0.5  → Clustering bueno
├─ 0    → Clusters solapados
└─ <0   → Puntos en cluster incorrecto

Inertia
├─ Suma de distancias² dentro de clusters
├─ Menor = mejor
└─ Use para comparar diferentes k

Esperado:
├─ Silhouette: 0.4 - 0.8
└─ Inertia: Disminuye con k
```
